# Banco de Dados

O LIneA disponibiliza acesso a catálogos astronômicos públicos e privados armazenados em banco de dados **PostgreSQL** por meio da plataforma [User Query](https://userquery.linea.org.br/).  
Essa plataforma permite a criação de **tabelas temporárias** na área do usuário através de consultas **SQL** e **ADQL**, e está integrada a outros serviços, como o **MyDB**, o [Target Viewer](https://target.linea.org.br/) e o [JupyterHub](https://jupyter.linea.org.br/). 

A documentação completa da plataforma — com instruções de uso, tutoriais e exemplos — está disponível em:  
[https://userquery.linea.org.br/cms/services/](https://userquery.linea.org.br/cms/services/)

!!! abstract "🔒 Acesso restrito"
    Parte dos catálogos disponíveis no banco de dados do LIneA possui acesso restrito, conforme políticas de segurança e de compartilhamento de dados dos respectivos projetos. Apenas usuários autorizados podem visualizar ou consultar esses conjuntos de dados.
