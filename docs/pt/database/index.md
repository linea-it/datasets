# Banco de Dados

O LIneA disponibiliza acesso a catálogos astronômicos públicos e privados armazenados em banco de dados Postgres através da plataforma [User Query](https://userquery.linea.org.br/). Esta plataforma permite a criação de tabelas temporárias na área do usuario através de consultas SQL e ADQL e está integrada a outros serviços como o MyDB, [Target Viewer](https://target.linea.org.br/) e o [JupyterHub](https://jupyter.linea.org.br/). 

A documentação completa da plataforma com instruções de uso, tutoriais e exemplos está disponível em: [https://userquery.linea.org.br/cms/services/](https://userquery.linea.org.br/cms/services/)
    
Acesse os detalhes sobre os catálogos disponíveis no banco de dados do LIneA navegando pelo menu à esquerda.
