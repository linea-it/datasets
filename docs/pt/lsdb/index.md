# LSDB Surveys 

Nesta seção, você encontrará informações sobre os conjuntos de dados públicos hospedados pelo **LIneA** no formato **[Hierarchical Adaptive Tiling Scheme (HATS)](https://hats.readthedocs.io/en/stable/)**, compatíveis com leitura através do **[LSDB (Large Scale Database)](https://docs.lsdb.io/en/stable/)**. 

O **LSDB** é uma biblioteca Python desenvolvida pelo **[LINCC (LSST Interdisciplinary Network for Collaboration and Computing)](https://lsstdiscoveryalliance.org/programs/lincc-frameworks/)** no âmbito do **[LSST (Legacy Survey of Space and Time)](https://www.lsst.org/)**, projetada para facilitar o acesso e a análise de grandes conjuntos de dados astronômicos. Um amplo acervo de dados públicos é disponibilizado pelo projeto no site [LSDB.io](https://lsdb.io).  

O **LIneA** hospeda uma cópia local desses dados, integrando-se ao ecossistema internacional do **LSDB.io**. Essa infraestrutura oferece maior eficiência na transferência de dados para usuários geograficamente próximos ao Brasil e permite que a comunidade astronômica brasileira acesse e analise esses conjuntos de dados de forma otimizada, utilizando seus recursos de **computação de alto desempenho (HPC)**.

Para acessar informações sobre os conjuntos de dados disponíveis no LSDB hospedado pelo LIneA, navegue pelo menu à esquerda.
