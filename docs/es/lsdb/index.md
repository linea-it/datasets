# LSDB Surveys

En esta sección encontrarás información sobre los conjuntos de datos públicos alojados por **LIneA** en el formato **[Hierarchical Adaptive Tiling Scheme (HATS)](https://hats.readthedocs.io/en/stable/)**, compatibles con la lectura a través de **[LSDB (Large Scale Database)](https://docs.lsdb.io/en/stable/)**.  

**LSDB** es una biblioteca de Python desarrollada por **[LINCC (LSST Interdisciplinary Network for Collaboration and Computing)](https://lsstdiscoveryalliance.org/programs/lincc-frameworks/)** en el marco del **[LSST (Legacy Survey of Space and Time)](https://www.lsst.org/)**, diseñada para facilitar el acceso y el análisis de grandes conjuntos de datos astronómicos. Para obtener más información, visita [LSDB.io](https://lsdb.io). 

El proyecto pone a disposición una amplia colección de datos públicos en [data.lsdb.io](https://data.lsdb.io).  **LIneA** aloja una copia local de estos datos, integrándose en el ecosistema internacional de **LSDB.io**. 
 
Esta infraestructura ofrece mayor eficiencia en la transferencia de datos para usuarios geográficamente cercanos a Brasil y permite que la comunidad astronómica brasileña acceda y analice estos conjuntos de datos de forma eficiente utilizando sus recursos de **computación de alto rendimiento (HPC)**.

Para acceder a la información sobre los conjuntos de datos disponibles en el LSDB alojado por LIneA, navega por el menú de la izquierda.
