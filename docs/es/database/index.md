# Base de Datos

LIneA ofrece acceso a catálogos astronómicos públicos y privados almacenados en una base de datos Postgres a través de la plataforma [User Query](https://userquery.linea.org.br/). Esta plataforma permite la creación de tablas temporales en el área del usuario mediante consultas SQL y ADQL, y está integrada con otros servicios como MyDB, [Target Viewer](https://target.linea.org.br/) y [JupyterHub](https://jupyter.linea.org.br/).

La documentación completa de la plataforma, con instrucciones de uso, tutoriales y ejemplos, está disponible en: [https://userquery.linea.org.br/cms/services/](https://userquery.linea.org.br/cms/services/)

Accede a los detalles sobre los catálogos disponibles en la base de datos de LIneA navegando por el menú de la izquierda.
