# Database

LIneA provides access to public and private astronomical catalogs stored in a Postgres database through the [User Query](https://userquery.linea.org.br/) platform. This platform allows users to create temporary tables in their personal area using SQL and ADQL queries, and it is integrated with other services such as MyDB, [Target Viewer](https://target.linea.org.br/), and [JupyterHub](https://jupyter.linea.org.br/).

Complete documentation for the platform, including usage instructions, tutorials, and examples, is available at: [https://userquery.linea.org.br/cms/services/](https://userquery.linea.org.br/cms/services/)

Access details about the catalogs available in LIneA’s database by browsing the menu on the left.
