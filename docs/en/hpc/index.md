# HPC - High-Performance Computing

LIneA provides access to **high-performance computing (HPC)** resources for the Brazilian astronomical community. These resources are intended to support research projects that require large computational capacity, storage, and the analysis of massive astronomical datasets.

The data available for analysis on our HPC resources include public and private astronomical catalogs, as well as data from cosmological and astrophysical simulations. Other datasets may be made available upon request, depending on technical feasibility and data-sharing policies.

The data hosted in LIneA’s HPC environment are organized and accessible through the **Lustre** distributed file system, connected to an **InfiniBand** network, allowing users to read and write data efficiently during their analyses.

For information about the datasets available in the HPC environment, browse the menu on the left.

!!! abstract "🔒 Restricted Access"
    In accordance with LIneA’s security policy and the proprietary data access policies of supported projects, part of the content about the data available in the HPC environment is restricted to authorized users.
