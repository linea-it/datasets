# Rubin Data Preview 1 (DP1) Object (lite)

The Vera C. Rubin Observatory Legacy Survey of Space and Time (LSST) is a 10-year astronomical survey designed to map the entire southern sky in unprecedented detail. It aims to address key questions about dark energy, dark matter, the structure of the Milky Way, and the solar system. This catalog collection was generated by the DASH pipeline and it is a trimmed version of the object collection. Learn how to access the data through the link below.
