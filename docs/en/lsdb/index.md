# LSDB Surveys

In this section, you will find information about the public datasets hosted by **LIneA** in the **[Hierarchical Adaptive Tiling Scheme (HATS)](https://hats.readthedocs.io/en/stable/)** format, compatible with reading through the **[LSDB (Large Scale Database)](https://docs.lsdb.io/en/stable/)**.  

**LSDB** is a Python library developed by **[LINCC (LSST Interdisciplinary Network for Collaboration and Computing)](https://lsstdiscoveryalliance.org/programs/lincc-frameworks/)** under the **[LSST (Legacy Survey of Space and Time)](https://www.lsst.org/)** framework, designed to facilitate access to and analysis of large astronomical datasets. For more information, visit [LSDB.io](https://lsdb.io).  

A broad collection of public data is made available by the project on the datasets page: [data.lsdb.io](https://data.lsdb.io/). **LIneA** hosts a local copy of these datasets, integrating into the international **LSDB.io** ecosystem.  


This infrastructure provides greater data transfer efficiency for users geographically close to Brazil and allows the Brazilian astronomical community to access and analyze these datasets efficiently using its **high-performance computing (HPC)** resources.

To access information about the datasets available in the LSDB hosted by LIneA, browse the menu on the left.
